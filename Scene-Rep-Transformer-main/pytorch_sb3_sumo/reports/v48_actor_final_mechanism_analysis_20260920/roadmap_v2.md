# v4.8/lr_half 后续研究路线 v2：术语与归因复核版

本文件是后续实施计划，替代 roadmap.md 作为路线说明；旧文档保留为讨论记录。本轮只审计、修订计划，不启动/停止训练，不修改正在运行的配置。

范围：Cross、CARLA；当前 seed 0 有限筛选；最终结果始终使用预定训练预算结束时的最终模型和直接确定性 actor。预测器、风险头、critic 或参考策略只用于训练/诊断，不增加部署选择器。

## 一、统一术语：编码器、辅助模块、表示方案、完整算法不是同一概念

| 符号/名称 | 定义 |
|---|---|
| E_MST | MST 场景编码器 |
| E_TTG | 拓扑－时序图编码器（TTG），含明确记录的必要读出接口 |
| P_SLT | 原 SLT 辅助预测模块及其目标 |
| P_GSLT | Graph-SLT 辅助预测模块及其目标；不是整个 TTG 编码器 |
| A | MST + SLT 表示方案 |
| B | TTG + SLT 表示方案，用于桥接归因 |
| C | TTG + Graph-SLT 表示方案 |
| k_pred | 辅助 latent 预测时距；当前 Graph-SLT 为一步 |
| n_TD | critic 多步回报长度；当前 full 为最多 16 个存储决策转移 |
| h | 某条样本实际可用的回报长度，bootstrap 使用 gamma^h |
| U | 冻结的优化、target 更新、训练预算等公共协议 |

完整 v4.8 还包括混合动作头、熵设置、辅助正则、多步回报及优化设置。C 不等于整个 v4.8。

实验中改变 k_pred 时固定 n_TD；改变 n_TD 时固定 k_pred 和辅助目标。诊断标签观察未来多久另行记录，不能把 probe 的未来标签跨度当成已改变训练预测目标。

## 二、总体顺序与阶段门槛

有限稳定性调参与现有模型诊断并行 → 冻结公共设置 → 表示桥接对照和正确回报对照 → 分别检验两项风险 → 仅修订被证据指向的机制 → 公平调参与关键比较的多训练 seed 确认 → 冻结测试和论文证据。

不以曲线必须单调上升作为进入机制研究的条件；也不把 seed 0 的较平滑曲线称为跨 seed 稳定性。

| 阶段 | 是否必要 | 主要任务 | 技术/模型 | 交付物 |
|---|---|---|---|---|
| 0 | 必做 | 固定模块边界与协议，正确性审计 | 配置指纹、关键单元测试、短 smoke test | 模块差异表、可复用单元表、claim-evidence 表 |
| 1 | 当前继续 | 完成既定稳定性筛选 | late_decay、batch64、target_slow；复用 lr_half/lr_quarter | 一套主设置，必要时一套备选 |
| 2 | 与1并行，必做诊断 | 比较表示内容、可读性、行为与失败类型 | 共享数据、线性/MLP probe、轨迹重放、梯度诊断 | 控制相关诊断与待证伪假设 |
| 3 | 必做 | A/B/C 在固定 n 下的归因，补正确回报对照 | 公共 hybrid actor，A16/B16/C16；C4 | 编码器方案、辅助模块与长度的条件效果 |
| 4 | 风险诊断必做；修订条件触发 | 检验短期预测与控制的对齐 | 固定 TTG 的目标替换；必要时 SPR、DeepMDP/DBC | 区分时距不足与目标不对齐 |
| 5 | 必做敏感性；新算法条件触发 | 检验回报长度的场景/表示依赖 | A4/A16/C4/C16；按需 n=8、B4；必要时 lambda/Retrace | 回报敏感性及交互分析 |
| 6 | 正式结论前必做 | 相同调参机会，关键比较多 seed | 有限 HPO、配对训练 seeds、分层 bootstrap | 最佳方法比较与机制重复证据 |
| 7 | 最后必做 | 冻结测试、统一压力条件、论文证据包 | 新 test seeds、交通/观测变化、安全/舒适指标 | 最终 actor 主表、消融、诊断、失败记录 |

## 阶段 0：实施前完成模块与协议对账

对 A/B/C 列出：编码器、输出/slot 接口、动作编码、predictor/projector、target encoder 与 target projector、EMA、辅助权重、slot 正则、梯度路径、各 optimizer LR、batch、tau、entropy、k_pred、n_TD、gamma、timeout、训练预算和评估协议。

每条因果对照只改变定义中的因素。以下差异不能隐藏：
- A/B 若除了编码器还改变 slot 正则或 target 更新，则只能称编码器方案整体差异；先匹配或增加独立对照，才可归因于编码器本身。
- B/C 比较的是辅助预测模块整体；predictor、projector、target 规则同时变化时，不能只归因于某个 loss 公式。
- 当前 Cross 的 tau 同时影响 critic target 和 Graph-SLT target encoder；稳定性候选收益不能全部解释为纯数值优化。
- 输出同为 128 维不代表容量相同。若 TTG 明显增参，结构性主张需要容量参照或明确局限；计算效率暂不作为淘汰标准。

正确性审计最少包括：真实 h 与决策/raw-step 单位、终止与 truncation 的 bootstrap、短尾/末端处理、one-step next observation 路径、target stop-gradient、actor 的直接确定性输出。确认任务 time limit 的定义，避免把不同终止语义误解释为不同 horizon 效应。

当前实现没有完整中间 entropy 累计与 off-policy 比率校正，不能只因采用 gamma^h 就宣称具有完整 soft n-step 或 Retrace 保证。若后续修正这些项，另立协议，不与旧结果混算。

正式强基线不能保留已经识别、且适用于其路径的回报计算错误。适用的正确性修复须同时覆盖 MST 基线与待比较方法；原始复现结果作为历史记录保留，明确区分“原始实现”与“统一修正协议”，不能把修复差异当成表示创新。

后续代码、配置、测试、运行清单与输出应使用独立的机制实验目录和协议标识，复用已有组件而不修改正在执行的稳定性轮次。新增 A/B 接口及 n/k 开关先做形状、梯度、返回目标的单元检查与短 smoke test；训练运行清单通过配置指纹去重。

复用依据为影响实验语义的代码、环境、配置、训练 seed、预算、checkpoint 和评估协议一致。方法名、文件名相同不够；无关文档更新不触发重跑。若只是缺少逐步诊断数据，可以说明目的后补采集，不必重训。

历史 10000–10099 已用于分析；当前调参评估 420000–420099 属于开发证据。最终测试另行冻结。CARLA 当前只有一个重建 traffic 文件，不同 seed 不等于跨交通文件分布外泛化。

## 阶段 1：完成既定有限稳定性调参

已核实当前计划：late_decay、batch64、target_slow 三个新候选；lr_half、lr_quarter 为复用对照；Cross/CARLA 各 seed 0，50k raw steps、5000 warmup、45001 次梯度更新、action_repeat=3。合计 6 个新增训练和 4 个复用模型。

沿用已经规定的评估与筛选口径，不因部分结果改变阈值。联合考虑最终 actor 的成功/碰撞/超时、后期回撤、持续退化、梯度/参数有限性及 Q/TD/entropy 行为。单次训练波动与跨训练 seed 方差分开命名。

图保持各场景/配置独立，沿用 episode20 + 每 raw-step EMA 0.999。分析同时保留原始 episode 数据。零填充、回填与 EMA 会影响形状，所以人工平滑图不是独立的收敛证明。后续新训练可在预定步数做独立 RNG 的 actor 开发评估，只测学习动态，不选择 checkpoint；不为补齐旧实验的中间评估而重训。

late_decay 同时改变多个 optimizer；batch64 不等计算量。tau 与 target encoder 的耦合必须记录。

优先冻结一套两场景均可比较的公共 U。若必须分场景采用不同 U，机制结论明确以各自 U 为条件；不能把观察到的全部差异归因于场景本质。强跨场景机制主张应另有公共 U 的检查。

保留一个主候选，必要时一个备选即可。若均有明显问题，先诊断数值、目标或数据原因，不无限扩大搜索。阶段1只形成筛选设置，不证明多 seed 稳定性。

## 阶段 2：现有最终模型的共享诊断

首先复用原有 MST behavior probe 数据；扩充时使用预先规定的 MST、原 v4.8、稳定候选轨迹混合分布。所有 encoder 对同一批 observation/history/action 编码。

按 episode/traffic seed 分组划分 fit/validation/test；同一 snapshot 的所有动作分支在同一组。standardization、probe 选择只看训练/验证部分。诊断中的罕见事件过采样与自然部署分布指标分开报告，不把改变类别比例后的输出直接称为自然风险概率。

| 诊断轴 | 技术 | 所回答的问题 |
|---|---|---|
| 信息与可读性 | Ridge/逻辑回归与固定容量 MLP | 差异是线性易读程度，还是更广泛的预测能力差异 |
| 控制相关性 | 多时距 action-conditioned collision/timeout/progress labels | 当前局部 probe 是否遗漏关键后果 |
| 动作优劣 | 公共继续策略下的状态分支 rollout、动作排序头 | 表示能否支持区分不同动作的结果 |
| 拓扑/时间适用条件 | 按交互强度、路线几何、预定义决策到结果时延分层 | 增益或退化发生在什么条件 |
| 优化机制 | target drift、有效秩、slot covariance、grad_repr 与 grad_TD 的夹角/范数 | 是否存在候选退化或梯度干扰线索 |
| 闭环行为 | 配对失败轨迹、lane logits、速度分布与 Q-gap | 表示改善能否被 actor/critic 使用 |

CKA 可辅助描述表示几何，attention 图可定位关注对象；二者都不单独证明质量或因果。

若使用 SUMO/TraCI 保存恢复进行动作分支实验，先验证恢复一致性，包括 wrapper 历史、交通调度和随机源。所有编码器使用相同继续策略的标签；结论限于该策略下的条件结果，不称最优 Q。原 critic 的绝对校准必须匹配 soft entropy、discount 与继续策略，不能用含熵 Q 减去无熵 episode return。

线性更好但 MLP 接近，可能是信息更容易读出，仍有价值；局部预测更好但风险/动作排序更差，是目标不对齐线索；风险预测更好但闭环不改善，需要检查动作头与价值学习。若所有表示均差，应使用 raw-input/privileged-state 诊断参照区分有限观测、数据覆盖和 probe 能力；这些参照不是严格理论上界。

## 阶段 3：加入桥接方案 B，先在 n_TD=16 下拆解

所有方案接入公共 hybrid actor/critic、同一 entropy 与 U。原始原生 MST 另保留为方法级基线，不能直接冒充公共接口下的 A。

必做桥接：
- A16：MST + SLT，16 步正确折扣。
- B16：TTG + SLT，16 步正确折扣。
- C16：TTG + Graph-SLT，16 步正确折扣。

B16 是当前“到底优/差在哪里”问题需要的桥接，而不应仅在 C16 明显优于 A16 时才做；总效应可能掩盖一个组件获益、另一个组件退化。

在控制项匹配的前提下：
- B16 - A16：SLT 下的编码器方案效果。
- C16 - B16：TTG 下的 Graph-SLT 辅助模块效果。
- C16 - A16：表示方案整体效果。

先同时补 C4（4 步、gamma^h），用于区分旧 minus_horizon 的折扣修正与长度变化。旧 4 步+gamma 只作历史正确性对照。

不一开始强制构建 MST+Graph-SLT。它需要有意义的 slot 读出接口，简单切分 128 维不保证公平。只有要讨论编码器×辅助模块完整交互时，才设计额外受控版本。

## 阶段 4：风险一——分别检验“时距不足”和“目标不对齐”

诊断必做；新目标由结果触发，不把所有相关模型一起堆入完整方法。

固定 TTG、n_TD、U 和其余辅助项，比较：
1. 当前一步 Graph-SLT。
2. 关闭预测项，保持其他项；必要时使用阶段3的 TTG+SLT 参照。
3. 若时距不足迹象明确，使用多步 Graph-SLT/SPR 类型预测，改变 k_pred。
4. 若普通预测不能保留控制信息，单独测试奖励、转移或风险/动作价值相关目标。

多步预测尽量共享 transition predictor，规范各时距损失的总权重并记录额外容量/更新量，避免把更大梯度预算误认为长预测时距的收益。1/4/8 等 k 是候选，按事件时延选择有限集合，不默认与 n_TD 同步改变。

多步预测需要连续的决策轨迹、动作序列、episode 边界和有效长度 mask。已有 n-step 聚合样本不自动等于可训练多步预测的序列数据；先验证 replay/数据集能提供正确序列，再实施 SPR 类型对照。

判据：
- 延长 k 改善未来预测、控制相关 probe 和闭环表现：支持时距不足的解释。
- 延长 k 只改善预测，不改善控制：不能认为风险已解决。
- 控制相关目标在同等条件下改善关键决策：支持原预测目标对齐不足的解释。
- 关闭预测项反而改善闭环：说明当前辅助项可能有害，但仍需检查权重、target 更新和梯度等具体原因。
- 证据不精确或覆盖不足：结论为未判明，不默认风险不存在。

候选模型边界：
- SPR：测试多步 latent prediction；更远不必然更控制相关。
- DeepMDP/DBC：提供奖励/动作条件转移相关的设计参照，理论假设不能直接移植。
- 若有限历史信息不足，先测试历史或记忆接口；不能要求图编码器恢复输入中不存在的信息。
- 若主张图和时间分别有效，还需训练拓扑弱化、时间聚合替代对照。仅测试时删除组件属于敏感性分析，不是训练消融。

## 阶段 5：风险二——正确折扣下的回报敏感性与交互

先完成 A4/A16/C4/C16，所有 n 都使用实际 gamma^h，k_pred 固定。比较条件成功率、安全和超时，同时报告训练 seed 层面的不确定性边界。

| 表示方案 | n=4 | n=16 |
|---|---|---|
| A：MST+SLT | A4，核心对照 | A16，核心对照 |
| B：TTG+SLT | B4，按下述主张触发 | B16，核心桥接 |
| C：TTG+Graph-SLT | C4，核心对照 | C16，完整锚点 |

初始核心共五个单元/场景、两场景十个 seed-0 单元。已有的完全匹配单元直接复用；这不是十个无条件新增任务。若两场景 C16 已与冻结 U 完全匹配，则尚需八个新训练单元。预算改变或额外桥接控制另列，不隐含在计数中。

“完全匹配”包含实际采用的回报修复状态、entropy/terminal 语义及代码版本；如果新统一协议改变了历史 C16 的训练目标或环境语义，它只能作历史锚点，不能计入上述两项复用。最终新增数量以审计后的单元表为准。

B4 在以下情况下变成必做：
- 要分解编码器×horizon 或辅助模块×horizon 的交互；
- 要声称 B16-A16 或 C16-B16 的结论在不同 n 下成立；
- 诊断提示组件抵消/效果对 horizon 敏感，而需要明确来源。

未完成 B4 前，只报告 A/C 表示方案整体与 horizon 的四格交互，以及 n=16 下的桥接分解，不报告完整 3×2 分析，也不把缺格当成零效果。

若 4/16 的差异或场景交互值得进一步区分，再补 n=8；n=1、32 等仅由具体问题触发。记录实际 h、预定义关键动作到结果的时间、nonzero-reward target 覆盖、bootstrap 比重、目标方差及行为策略偏离。长 episode 不等于关键决策时延长。

如改变 k_pred 后再研究 n，应固定新的 k，另列实验；不能将 k 与 n 同步变化的收益归给其中一个。

只有确证固定 n 敏感性或 off-policy 偏离造成实际问题后，才考虑 lambda-return/Retrace 类型修订。Retrace 需要记录行为策略概率、处理混合动作密度与 mask、匹配 soft objective；没有行为概率的旧 replay 不具备严格比率校正条件。

这里的目标是判断本项目中回报长度是否过度敏感、收益是否稳健，以及选择规则是否合理；不是证明某个 n 对所有场景普适最优。场景偏好不同 n 本身不代表方法失效，也不自动要求新增自适应模块。

## 阶段 6：公平调参、关键消融复现及最终模型冻结

公共 U 下的因果对照与同预算 HPO 后的最佳方法表现分开报告。从完整方法选出的 U 不保证是 MST 的最佳设置。

对最终保留的原生 MST+SLT 与完整方法提供预先规定、相同预算的搜索机会；按需保留公共 hybrid 接口 A 作解释性基线。保留全部试验，不重复协议相同的已完成单元。

当前仍按用户要求 seed 0 筛选。形成方向后再安排多个独立训练 seeds：可先3个确认方向，关键最终比较争取5个或更多，由不确定性和预算决定，不是当前立即启动指令。

多 seed 不能只覆盖最终完整方法与基线：支撑主张的关键消融（例如 B16/C16 或 C4/C16）也要有训练重复。否则主性能稳健，机制结论仍可能依赖 seed 0。

若最终 HPO 改变了与机制耦合的设置，公共 U 的机制结论仍只对该 U 成立。要将解释用于最终优化方法，应复核关键对照，而不是把旧消融直接移植。

分场景报告均值、种子间差异、配对效应与区间。评估 episodes 嵌套于训练模型之下，不能替代独立训练 seeds。采用分层 bootstrap；RLiable 可作为方法参考，两个场景不宜仅用一个聚合分数掩盖差异。

## 阶段 7：冻结评估与论文证据包

方法与超参数冻结后再打开新的固定 test seeds 和预定义交通/观测条件。不得因胜负结果增删条件。CARLA 若要主张跨交通分布泛化，需要额外构造并验证交通条件，不能仅换随机种子。

主指标：成功、碰撞、超时、路线完成。
辅助指标：实际最小距离、适用条件下的 TTC/PET、真实加速度与 jerk、急制动、速度限制违反、完成时间。明确实际采样间隔、适用条件、缺失/截断与条件统计。联合报告安全与任务进展。

证据包至少覆盖：
- 原生强基线与完整方法的最终 actor 主表；
- 公共接口的 A/B/C 桥接与正确折扣的必要因子对照；
- 风险一的控制相关诊断及被触发的目标干预；
- 风险二的 horizon 敏感性与适用条件；
- 原始日志、各配置独立的 EMA 图和固定步 actor 诊断；
- 关键比较的多训练 seeds；
- 参数/计算说明、失败候选、零效果及全部调参记录。

claim 对应：
| 拟议主张 | 必需证据 |
|---|---|
| 表示方案整体改善控制 | 匹配 A/C 闭环对照 + 方法级强基线 |
| TTG 编码器有独立作用 | 控制其他差异的 B-A，必要容量参照 |
| Graph-SLT 辅助模块有独立作用 | 同一 TTG 下 C-B/预测项关闭对照 |
| 短期预测错配被解决 | 固定 n 下的目标干预 + 控制相关诊断 + 闭环效果 |
| 多步回报收益稳健 | 正确 gamma^h 下的 n 对照、场景/表示交互及训练重复 |
| 组合互补 | 完整相应因子对照与交互，不由两个独立 probe 推断 |
| 算法具有投稿所需创新 | 机制证据加原始文献比较；正确折扣或固定 n 本身不自动构成创新 |

若模块只能改善局部 probe，无法获得相关控制证据，应弱化主张或修订方案。若收益主要来自正确性修复或优化，应如实归因。本路线提高可验证性，不保证某个投稿等级的录用。

## 两个 GPU worker 与复用原则

当前两个 worker 继续既定稳定性任务；已有数据分析、probe 和计划审计尽量使用 CPU。阶段3按去重后的单元清单排队，可将表示桥接与回报对照分配给两个 worker。后续只训练被明确主张或证据触发的单元，不一次性启动所有模型/所有 k/所有 n 的组合。

所有新预测器、risk heads、reference policies 和 critic 分支只用于训练/诊断。最终部署保持最后模型的直接 actor，不用额外选择器制造收益。

## 理论来源与适用边界

- [Alain & Bengio: Understanding intermediate layers using linear classifier probes](https://arxiv.org/abs/1610.01644)：线性可读性诊断，不等于控制充分性。
- [Kornblith et al.: Similarity of Neural Network Representations Revisited](https://proceedings.mlr.press/v97/kornblith19a.html)：CKA 的表示相似性，不是质量排序。
- [Schwarzer et al.: Data-Efficient Reinforcement Learning with Self-Predictive Representations](https://arxiv.org/abs/2007.05929)：SPR 多步 latent prediction 的参照，不保证本项目效果。
- [Gelada et al.: DeepMDP](https://proceedings.mlr.press/v97/gelada19a.html) 与 [Zhang et al.: Learning Invariant Representations for Reinforcement Learning without Reconstruction](https://arxiv.org/abs/2006.10742)：reward/transition 相关表示的理论与实现参照，需要验证适用假设。
- [Munos et al.: Safe and Efficient Off-Policy Reinforcement Learning](https://arxiv.org/abs/1606.02647)：Retrace 的 off-policy 多步校正，不证明当前 n=16 的因果来源。
- [Agarwal et al.: Deep Reinforcement Learning at the Edge of the Statistical Precipice](https://arxiv.org/abs/2108.13264)：训练运行层面的不确定性报告。
