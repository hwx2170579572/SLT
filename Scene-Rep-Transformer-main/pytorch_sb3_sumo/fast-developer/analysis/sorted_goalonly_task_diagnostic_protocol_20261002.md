# sorted/depart4 冻结模型任务诊断协议（2026-10-02）

## 动机与边界

用户在本轮补充授权必要的额外诊断评估，要求把模块落实到驾驶难点、失败机制与成功率改进。此次诊断不更新网络、优化器或 replay，不替代、不改写已完成的正式 100k 实验。新增结果单列为冻结策略干预评估，不计入正式训练方法结果数。

原正式方法：sac_mlp_d1_st_rt_topo_goalonly_v1；场景 intersection_sorted_depart4p0；seed 0；100000 raw steps / 95001 updates；final_model SHA256：
17465d202736d4640d46459f78bc4b55cef939ab6e3aa39b9cad63a981f1c5f5。

已验收的原终评为 24 成功、47 碰撞、29 超时、0 偏航。现有轨迹显示 29 次超时均在早期由 -E1_2 进入不直连路线下一 edge 的车道，后续长时停滞。这里的“不直连”是当前车道的拓扑属性，不代表在所有位置都无法通过后续换道恢复。可达 token attention 与执行动作的路线保持条件是不同层次。

## 三臂设计

两个独立评估 worker 调度三项评估，各 100 回合，复用原 seed 10000–10099 和同一 30 条交通模板。源码核对发现原正式终评由 _evaluate_saved 使用 CPU 加载模型，故诊断也保持 CPU；此前两路正式训练使用 CUDA，与终评设备分开记录。所有臂固定同一 checkpoint、环境、奖励、终局规则和确定性动作选择。

| 诊断臂 | 唯一主动干预 | 目的 |
|---|---|---|
| frozen_control | 无；只增加诊断记录 | 核对当前评估实现能否重现正式结果，为两个干预提供同代码对照 |
| topology_goal_off | 在冻结策略中关闭目标 Topo 残差的实际注入，其他参数和动作执行不变 | 测试当前已训练策略的该分支对闭环任务结果的影响 |
| route_lane_veto | 仅在当前车道已知直连下一路线 edge、请求目标车道已知不直连时，将横向请求改为保持；纵向指令保持原值 | 测试错误选道是否为可通过明确动作规则消除的失败环节 |

route_lane_veto 在未知、无下一 edge、无可判定目标车道等情况下不猜测，不执行否决，记录原因。规则不读取未来交通状态，也不承担碰撞安全保证。它可能排除本可先换出再换回的动作，所以属于诊断干预，不能称为所有情形下最优的控制规则。

## 核验与输出

- 开始前记录模型实际 SHA、模板文件 SHA、源码/参数快照、base_method 和 intervention；结果写入独立 runs/sortg3_causal_1002，原正式目录只读。
- 不调用 learn；校验参数 SHA/张量或 checkpoint 身份未改变，训练更新计数不增加。
- 每臂完整 100 个唯一种子，终局互斥；shaped return 与 raw return 分列，六个奖励分量逐回合对账。
- 对 control 核对原始每种子结果，而非只核对总数。若不一致，先查版本、评估与干预隔离；明确记录差异，不能把差异归因于方法，也不能选择性使用有利的对照。
- 保存原始请求、实际送入环境的动作、否决依据、实际车道变化及恢复、当前/目标车道直连状态。请求发送成功不等于实际完成换道。
- 保存同时间窗的目标速度、实际速度、停驶时长、冲突/TTC 可用性与碰撞快照。缺失值与安全状态分开。
- 关键状态探针补足中途选道/冲突事件；不增加 SUMO 步或评估回合。唯一状态数、触发标签数、variant 行数分别报告。

## 预先约定的解释

主要终点为每种子成功/碰撞/超时/偏航转移，不以回报或激活范数代替成功率。辅助终点为路线不直连时长、实际车道变化、停驶、碰撞时空分布及 TTC 的有效覆盖。

1. 若 goal_off 相对 control 提高成功率并减少超时：支持该冻结策略下当前目标 Topo 注入存在任务损害；不等于证明该结构重新训练后必然无效，也不等于所有 Topo 设计都无用。
2. 若 goal_off 降低成功率：说明该分支至少提供了当前策略依赖的有用信息；整套方法低分仍需解释为学习、组合或行为执行问题。
3. 若 route_lane_veto 将超时转成成功：支持路线保持缺口是可干预的任务失败环节。
4. 若否决主要将超时转成碰撞：说明解除选道停滞仍没有解决冲突车辆交互和通过时机，不能称为成功修复。
5. 若否决不改善超时：检查规则实际触发、实际车道、其他堵停和纵向动作；不继续把所有超时归咎于直连条件。
6. 两种干预可能同时有效或同时无效；它们改变的层次不同，不据其中一项宣称另一层因果已排除。

100 个评估种子属于固定单训练种子的场景评估，不是 100 次独立训练。按配对种子比较并保留模板分组；不外推到 DARRL 或其他密度场景。

## 理论依据与适用范围

- [Jain & Wallace, 2019](https://aclanthology.org/N19-1357/) 与 [Wiegreffe & Pinter, 2019](https://aclanthology.org/D19-1002/) 支持对 attention 解释进行受控检验，不能仅凭权重认定用途；论文研究领域为 NLP，不直接证明本项目 RL 的结论。
- [ERASER, 2020](https://aclanthology.org/2020.acl-main.408/) 提供以输入/表征移除后的预测变化检查依赖性的思路；本项目进一步用冻结策略闭环结果检查任务后果，仍须区分分布外干预与重训练消融。
- [Safe Reinforcement Learning via Shielding](https://ojs.aaai.org/index.php/AAAI/article/view/11797) 区分策略表示与动作执行时约束。本次简单路线规则不是论文中带形式保证的完整 shield。
- [SUMO TraCI 官方文档](https://sumo.dlr.de/docs/TraCI/Change_Vehicle_State.html) 明确区分换道请求、实际成功换道以及目标速度与实际执行速度；本分析以真实轨迹验证执行结果。
