# 正常训练与评估内置诊断协议

用户要求：判断模型所需、且能从正常训练和评估中取得的信息，应随原流程直接采集和汇总。不得把这些信息推迟到训练后重新进行大量环境回放或诊断训练。短程测试只用于验证采集实现正确性。

补充边界：确实需要额外回放、干预或对照实验才能回答的问题，留到本轮训练和评估完成后，根据已有结果再安排。这不是禁止额外诊断，而是避免为本可随流程取得的信息重复运行实验，也避免在本轮训练前展开研究性诊断。

## 研究比较

- SAC+MLP 是纯强化学习基线；MST+SLT 是强基线；full 是待逐模块拆解的方法。
- 本轮目标为 SAC+MLP 与 ST-RT 各自从零连续训练 100,000 raw simulator steps，两个 CUDA 训练进程并行，随后执行各自正常的最终评估。
- 保持已用的交通密度、奖励、训练预算和评估种子协议。当前 depart_scale=4 的实际工厂使用全部 30 个交通文件；不能将名称中的 frozen_80_20 当作真实留出测试集。
- 单个训练种子仅支持探索性判断，不能据此宣称稳定优越性。相同评估种子便于配对比较，但重复交通模板也不能当作独立场景族。

## 正常流程需要留下的证据

1. **可追溯性**：方法、配置、实际设备、训练/评估阶段、实际 SUMO 种子、交通文件清单及散列、raw step 与策略决策步。
2. **动作和控制**：策略动作、实际送入环境的动作、目标速度/车道控制、实际速度及由连续物理状态计算的加速度。区分环境基础奖励和训练器实际收到的奖励。
3. **风险状态**：自车与周车位置、物理速度、尺寸、道路/车道、策略实际观测到的邻车 ID；候选冲突车辆及其相对位置、接近速度、CPA 和 TTC。
4. **结束证据**：成功、碰撞、越界、超时或中断，精确碰撞事件和参与者（接口可提供时），碰撞时自车状态来源及时间。车辆移除后的前一帧位置必须注明，不能当作精确碰撞位置。
5. **优化证据**：已有 actor/critic loss、熵系数、表征损失等标量按固定低频持久化；任何新增诊断只能利用既有计算结果，不额外更新参数或消耗训练随机数。
6. **自动汇总**：每回合与每阶段自动输出结果、速度、停滞、动作分布、低 TTC 风险和观测覆盖率，以及优化指标变化。缺失信息必须明确标注，不能填零冒充测量结果。

## 指标解释边界

- 物理坐标采用世界坐标，长度为 m、速度为 m/s、时间为 s，heading 为从 +x 轴逆时针的弧度。诊断坐标转换不得修改策略观测。
- 恒速固定朝向 OBB TTC 是当前运动外推下矩形首次接触时间，不是 SUMO 已发生碰撞的事实，也不是考虑未来转向/制动的真实剩余时间。
- 中心距离 TTC、CPA 和矩形 TTC 分别保留定义；不可混用。没有预测碰撞、几何缺失和自车状态过期应可区分。
- 风险统计需同时报告采样范围、邻车数量上限、遗漏数以及观测 ID 是否可用。未在策略观测中的冲突候选车辆不等于策略观测机制存在错误。
- 动作接近边界仅在已知动作空间下解释为饱和。目标速度与实际速度分开分析；不能由负动作直接推断车辆已经制动。
- 所有占比必须附相应有效样本分母。中断回合与完整评估回合分开统计。

## 后续判断顺序

先检查实现与采集覆盖率，再比较终止结果；随后用同次评估的动作、实际运动、风险车辆和终止证据区分“控制未生效”“观察遗漏”“在已观察风险下仍采取激进行为”等假设。结合优化轨迹判断训练不稳定的可能性。证据不足时保留未知，不直接叠加新模块或改变评估协议。

后续如提出新的实验假设，应先检查正常训练/评估是否已能产出所需证据；若能，应扩充这套内置采集再启动实验。
