## Status convention

- **Pending**: the required artifact or check has not been independently run and recorded.
- **Passed**: every stated implementation check for that gate has passed with command, environment, source/config hash, output, and limitations attached.
- **Failed**: a meaningful check exposed a defect; repair and rerun the same check. Do not weaken or remove it to obtain a pass.
- Empirical status is reported separately. Passing code tests does not establish better success, fewer collisions, predictive calibration, or novelty.

## Stage 2 initial geometry audit

The initial centerline-proxy map compiler failed the Stage 2 geometry gate. This is an implementation-contract finding, not a training outcome or an episode failure-rate result. On the frozen `intersection_sorted_depart4p0` public map, the typed topology graph yields 106 unordered relation pairs: 88 conflict and 18 merge. The initial compiler found centerline intersections for 55 conflict pairs (67 intersection-point candidates clustered into 54 proxy zones), added a nearest-point fallback for 12 more conflict pairs, and projected no zone for the remaining 21 conflict pairs or any of the 18 merge pairs. Thus 39/106 typed relations had no event-zone projection, including every merge relation.

The current zones are built from lane-centerline intersection/near-point buffers. The fallback accepts centerline separation up to `max(2.5 m, lane widths)`; proxy radii are based on lane width and close points are clustered. The collector extends longitudinal entry/clear distance using actor half-length, but the zone construction and event interval do not model a heading-aware vehicle footprint, actor width, or swept body through curved/merging paths. A topological merge relation can therefore be present in the graph while its actual convergence area is absent from the event representation. The 21 unprojected conflict relations cannot be assumed to be physical swept-body conflicts from topology alone, and the current 12 fallback pairs remain approximate point proxies.

The first `corridor_v2` static compiler and audit also did not pass Stage 2: lane-centerline point proxies and nearest-point fallback did not represent all typed relations or vehicle-body geometry. The current v2 audit records that historical failure separately from the repaired static topology accounting below. Full Stage 2 still requires the stated synthetic crossing/parallel/merge/following/curved/multi-size/boundary tests and live candidate-route coverage. Stage 3 live smoke stays pending behind geometry and the other required implementation gates.

## Stage 0 executable test plan

The target test uses the actual independent code in `fast-developer/scene_event/protocol.py`, `replay.py`, and `policy.py`; it must not require SUMO, a model training run, network access, or CUDA. The owner test files are `tests_sb3_sumo/test_scene_event_protocol.py` and `tests_sb3_sumo/test_scene_event_policy.py`.

1. **Decision horizon arithmetic and two clocks.** With `gamma=0.9`, four rewards `(1, 2, 3, 4)` must produce `1 + .9*2 + .9²*3 + .9³*4 = 8.146` and discount `.9⁴ = .6561`. Here `k` counts policy decisions, while `raw_steps` counts 0.1-second physical ticks; a 1- or 2-tick decision is still one decision and must not be silently treated as a 3-tick decision. At the exact global raw-collection cap, omit a nonterminal final action-repeat fragment shorter than 3 ticks from replay and flush pending returns at the previous complete decision's actual next observation; retain and count the omitted ticks separately. A short action that reaches the real 60-second episode deadline is a true terminal transition and stays in replay, with its actual raw duration recorded. Neither case changes the decision-counted `gamma**k` rule.
2. **Deadline terminal versus collection truncation.** A synthetic 60-second deadline transition carries remaining time `0`, `terminated=True`, `truncated=False`; its n-step sample must stop at the deadline and `soft_bellman_target` must equal the accumulated reward regardless of target-Q/log-prob values. An external truncation must stop the n-step sequence but retain `terminated=False`, use the last real physical observation (including its remaining-time field), and bootstrap with the actual `gamma**k`. The reset observation must never enter the transition.
3. **No episode mixing.** A boundary flush must emit every shortened suffix from only the terminating episode. Appending a new episode after a properly ended boundary must be accepted with its own episode id. Changing episode id or skipping a decision while a sequence is pending must raise instead of joining returns across that gap.
4. **Immutable raw observations and replay re-encoding.** Mutating a collector-owned writable array after replay insertion must not change the stored transition; replay storage arrays remain read-only and a sampled batch is an independent copy. A small deterministic encoder applied to sampled raw observations must produce a different `z` after its weights change while the replay observation remains unchanged; replay must not contain a cached `z` substituted for source observations. Also mutate a pending source observation before its n-step transition is emitted; if assembly retains the alias, this test fails and the collector/assembler ownership boundary must be repaired.
5. **Frozen protocol validation.** The configuration must reject any non-60-second or nonterminal deadline setting and unknown protocol/method identity. The real environment integration must separately assert that SUMO `max_time` under this new protocol returns `terminated=True` and `truncated=False`, while the historical environment/run path remains unchanged.
6. **Reward-only endpoint target contract.** Numeric tests must lock the agreed target to discounted environment rewards plus one endpoint soft bootstrap. They must not silently add intermediate entropy or importance-sampling terms. Documentation and names must call it an approximate reward-only n-step/endpoint-soft target, not an exact standard soft n-step operator.

For actual arithmetic in item 1, `(1,2,3,4)` sums to `8.146` at `gamma=.9`. Tests should calculate the reference independently rather than call the production helper to compute both expected and actual values.

That shared capacity was reduced from 20000 for the measured host-memory constraint recorded in `experiment_protocol.md`, not for performance tuning; preserve uniform sampling and FIFO overwrite in both arms. One concrete optimizer difference remains: the legacy `algos/sb3_torch/sac.py` builds `ent_coef_optimizer` as Adam with `betas=(0.5, 0.999)` and `eps=1e-7`, while the new `SceneSAC` currently uses NAdam for `log_alpha`.
