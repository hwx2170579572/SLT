## 已有证据与判断

数据均来自已有 v4.8 训练日志，按用户指定的 episode20 + 每原始步 EMA999 重算。可审计数字和输入哈希在 `r48s1/evidence/curve_diagnostics.json`；图在同目录。EMA 是回顾性窗口信号，不是未经平滑的逐回合成功率。

| 观察 | Cross | CARLA |
|---|---:|---:|
| lr_half 在 30k 的成功率 EMA | 0.6580 | 0.9412 |
| lr_half 在 40k 的成功率 EMA | 0.7082 | 0.6915 |
| lr_half 最后完整回合处成功率 EMA | 0.6768 | 0.8712 |
| lr_half 后10k成功率曲线 std | 0.0700 | 0.0560 |
| lr_quarter 后10k成功率曲线 std | 0.0456 | 0.0623 |
| lr_quarter 最后完整回合处成功率 EMA | 0.7214 | 0.6917 |
| lr_half 后10k完整回合数 | 24 | 64 |
| lr_half 后10k原始回合成功率 | 0.7083 | 0.8281 |

1. **事实/观察**：两个场景都有明显回撤。CARLA 30k 到 40k 下降约25个百分点，之后部分恢复。Cross 也存在中后段峰谷。这不是单凭曲线能确认的数值发散。
2. **反证**：将固定学习率从5e-5继续降为2.5e-5并未共同改善两个场景。已有 lr_quarter 直接复用，不重新训练，也不把“学习率越低越稳”当成事实。
3. **优化日志的局限**：CARLA 聚合 critic loss 均值约0.122、最大值约4.515；Cross 均值约0.033、最大值约0.234。聚合文件缺少时间对齐，不能把 loss 峰值直接归因到40k附近的下降。熵系数末期约0.023，且车道熵系数原本为0；低车道熵本身不能证明训练异常。新运行保留优化轨迹以检验时间对应关系。
4. **排除无效干预**：末期决策步数 Cross 16708、CARLA 16759。即使加上每个完整回合最多一次边界重复插入，回放条目上界分别16818、17091，均低于容量20000。因此扩大到40000不会增加本轮可抽样数据，不纳入筛选。
5. **谨慎使用历史参照**：旧 tau_half/tau_double 同时使用1e-4学习率，不等于本轮5e-5下的 τ 单因素实验。较慢 τ 并未普遍改善 Cross，故其优先级低于衰减和 batch。原始 control 的训练代码等价性尚未完全建立，只放入历史诊断图，不参与本轮公平排名。
6. **部署协议已改变**：此前 target-critic/fusion 的部署成绩不能直接用于本轮排名。所有10个最终模型重新在同一组新开发种子上做 actor-only 遥测评估，以获得原记录中没有的行为指标；这不涉及重复训练。

## 固定候选：三组新增，两个已完成对照

| id | 相对 lr_half 的唯一干预 | 可证伪的假设 | 预期可观测结果 / 否定条件 |
|---|---|---|---|
| lr_half | 无；复用两场景模型与曲线 | 固定参考 | 所有差值均相对它报告 |
| lr_quarter | 已有固定 LR=2.5e-5；复用 | 全程降低步长能否稳定训练 | 提供已有正/负证据，不再运行训练 |
| late_decay | 原始步≤20k：5e-5；20k到50k线性降到2.5e-5 | 早期探索/学习需要较大步长，后期持续同等强度更新诱发回撤 | 保留前段学习进展，后段 std/回撤下降；若后期仍降或学习停滞则否定 |
| batch64 | batch32→64；LR=5e-5、τ=.005 | 小批量估计噪声是后段振荡来源之一 | 更新损失轨迹和曲线振荡同时下降；若仅变平而表现下降则不通过 |
| target_slow | τ=.005→.0025；LR=5e-5、batch32 | 目标网络跟随过快使自举目标不稳定 | 两场景回撤/振荡改善；若学习变慢或 Cross 继续恶化则不支持 |

20k 是统一预设的晚期衰减起点，在观测到的中后段退化之前；不是通过新结果逐场景搜索得到。2.5e-5 是已有证据覆盖的温和终点，不继续扩大未知范围。衰减同时作用于 actor、critic、representation 和自动熵系数的优化器，并按原始步对应的每次梯度更新生效。

不改变网络、奖励、交通密度、观测、50k预算、5000 warmup、45001次梯度更新、action_repeat=3、gamma、熵目标、梯度裁剪或历史数据。batch64 每次更新使用更多样本，计算量增加按用户要求允许，但须记录以避免声称同等计算成本。

## 自动分析与筛选

- 每个场景分别输出奖励与成功率；每个候选有与 lr_half 单独对比图，也有同场景总览。绝不跨参数或场景平均训练曲线。
- 原始回合：全程与40k–50k尾段均值、总体方差/std、回合数；1000原始步分箱保留空箱为缺失。
- EMA曲线：AUC/观察长度、终点、尾段std、尾段斜率、总变差扣除净变化、5k之后最大回撤、峰值到尾段下降。
- 收敛速度代理：首次达到80%且持续至少5k原始步；未达标保留null。尾段平台启发式：后10k均值≥.8、std≤.03、斜率绝对值≤.005/1k。它们不是收敛证明。
- 数值发散与表现退化分开：新训练检查每次train调用的标量是否有限，每约100次更新和末期检查所有参数；≥20个百分点回撤另记性能退化。历史缺少逐更新日志时如实标注。
- 先逐场景检查 actor部署成功率、碰撞率、超时率相对基准不劣超过3个百分点；训练尾段成功率不低超过3个百分点、奖励不低超过.06，成功率AUC不低超过.02。再要求最大回撤不增加超过.02、振荡不增加超过10%、尾段成功率EMA std至少改善10%。两个场景都满足才列为候选；按较差场景的尾段std相对比例排序。
- 阈值只是预先固定的开发决策规则，无统计显著性含义；若无人通过就报告“暂无”，不放宽条件追求赢家。效率只报告，不淘汰。

规模：6个新增50k训练 + 4个复用模型；10个最终模型×100开发评估回合=1000回合。共同 SUMO 种子420000–420099，物理evaluation分区、验证用途。CARLA 场景共享交通模板，不能声称未见模板泛化或未接触最终测试。

新增结果独立保存在短目录 `r48s1`；原 phase2/phase3 源码和实验不修改。单次 seed 0 只能筛选，不能支持跨训练种子稳定性或投稿级最终结论。
