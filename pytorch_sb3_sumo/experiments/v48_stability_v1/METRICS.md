# 评估指标与曲线定义

所有模型：训练最后50k模型、deterministic actor直接前向、每回合相同SUMO种子与交通/网络文件哈希。回合结果、每原始步遥测、动作记录均保存。默认100回合；正式训练seed仅0。

| 类别 | 指标和单位 | 解释边界 |
|---|---|---|
| 任务表现 | 成功/碰撞/偏离路线/超时率；回报均值/std；成功完成时间秒 | 事件可重叠；完成时间只统计成功回合，并同时给成功率 |
| 行驶效率 | 回合平均速度和P95 m/s、观测里程m、停止秒数和比例、回合原始时长 | 停止阈值速度<.1m/s；不能把低速低jerk独立当成优胜 |
| 纵向舒适度 | 加速度RMS和绝对P95 m/s²；jerk RMS和绝对P95 m/s³ | 加速度来自TraCI；jerk用相邻原始步差分及实际时间差 |
| 剧烈动作 | a<-3、a>3m/s²及abs(jerk)>5m/s³的观测比例 | 项目诊断阈值，非统一法规或舒适性标准 |
| 横向行为 | 横向速度绝对值均值；v×yaw_rate的横向加速度代理；同一路段内实际车道变化数 | 转角解缠绕；路段切换不计车道变化；横向加速度明确为代理量 |
| 跟车风险 | 最小跟车TTC、TTC<1.5/3秒的观测比例、接近前车条件下比例；最小时距 | 搜索前车距离100m。TTC=物理车距/正接近速度；仅纵向当前前车，不是交叉/行人全冲突TTC |
| 约束和风险暴露 | 速度超过allowed_speed+.1m/s的比例、不可行动作比例、碰撞回合/观测公里 | allowed_speed含车辆速度系数，不能命名“违法超速率”；碰撞/公里与成功率、里程覆盖联合解释 |
| 数据完整性 | 原始步遥测覆盖率、jerk样本数、前车比例、接近前车样本数、动作mask覆盖率 | 无前车/无接近时最小TTC为null。其他指标异常读取直接失败，不静默补0 |

TraCI getLeader 的距离需加上ego minGap才能得到物理车距；ego消失的终止步不构造不存在的状态。观测里程仅累计连续可观测区间，因此消失时为下界，并标记censored。记录初始状态用于第一步差分；插入车辆的reset步骤不进入控制阶段统计。

每个回合先计算行为指标，报告中给等回合权重均值、总体std/方差、有效回合数。碰撞/公里由总碰撞回合数除以总观测公里。无跟车事件的“最小TTC”不当作0秒，不用0补齐缺失；阈值风险暴露率的分母分别明确为全部可观测步或有接近前车的步。

暂不提供红灯违规、PET、路线完成百分比或跨冲突TTC：当前实现没有足够可靠的事件/冲突轨迹定义，不能以近似零值充数。安全替代指标不能证明实际安全。

API依据：[SUMO Vehicle Value Retrieval](https://sumo.dlr.de/docs/TraCI/Vehicle_Value_Retrieval.html)；冲突指标适用范围参照[SUMO SSM Device](https://sumo.dlr.de/docs/Simulation/Output/SSM_Device.html)。本项目并未启用SSM全冲突事件采集。

曲线严格复用 `tools/report_phase2_curves_reference_style_v2.py`：20回合槽位、前期不足补零、当前回合窗口回填其原始步、初始EMA=0、每原始步0.999×旧值+0.001×当前值、每100步显示并追加最后完整回合终点。阴影=窗口总体std/sqrt(20)后同样EMA，成功率上下界裁剪到[0,1]。阴影不是跨种子置信区间，奖励不裁剪。原始训练reward沿用Monitor记录定义，不通过重定义改善曲线。
