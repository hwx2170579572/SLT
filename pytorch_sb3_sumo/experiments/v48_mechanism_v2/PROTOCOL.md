# 阶段2诊断协议（结果生成前固定）

阶段0历史诊断门槛已通过。12项现有测试、7项数值回报检查、8个最终模型的actor与梯度接口检查通过；这不消除历史实验混杂。未来受控训练仍须冻结公共 U、完成 A/B/C 接口及统一回报协议。

## 固定模型与数据

- 两场景：Cross、CARLA。四个编码器：历史 MST+SLT、v4.8/lr_half、已完成的 late_decay 与 batch64。后两项作为优化条件诊断，不能预先称赢家。
- 先复用已有 MST behavior 的 40 回合数据，复现原 Ridge 分数；旧 minimum_ttc 实为最近接近时间代理，不是已验证碰撞 TTC。
- 新控制数据采用三个预定行为 actor：MST、原 full、late_decay（候选列表中首项，不按本轮分数挑选）。各场景各40回合，共240回合，交通种子530000–530039，均使用相同高密度 V4 环境；MST 忽略额外 lane mask 输入。该公共诊断环境不冒充原历史100回合评估。
- 所有模型只用最终检查点，确定性 actor；新增数据目的是补旧数据缺失的动作、next observation、物理 mask、事件与时间戳，不重新训练策略。
- CPU单线程、SUMO串行、禁用CUDA、低进程优先级。运行收据和哈希支持断点续跑；不能重复已有完整且身份匹配的诊断回合。

## 读出与不确定性

- 复现旧 probe：原 seed73 / 28训练episode / 12测试episode / Ridge 0.001，不改旧结果。
- 新线性与MLP比较采用同一分组的 fit/validation/test；按交通seed分组，配对行为和动作分支始终同组；预处理仅fit数据。
- 固定 MLP：两层128隐藏单元、ReLU、Adam学习率0.001、weight decay 0.0001、最多100 epoch，validation early stopping patience12。线性正则候选0.001/0.1/1/10，只用validation选择；不看test调参。probe初始化seed73。
- 连续目标报告R²、RMSE、episode配对误差差；事件目标报告ROC-AUC/AP/Brier和类别覆盖。缺少正/负事件时不输出伪造分数。confidence interval按交通seed重采样，不能解释为RL训练seed方差。
- 未来标签跨度为1/4/16/32个决策；记录实际raw-step时间和终止。成功后竞争终止记已结束、不延长虚构轨迹；终止帧缺失的距离目标标记censored。
- 区分有/无当前动作条件的probe。未来行为仍由收集策略决定，关联读出不能充当反事实动作价值。

具体计算预算：未来1/4/16/32跨度均做线性读出；MLP与不输入动作的控制聚焦预先指定的16决策跨度，适用于progress/collision/timeout三项。MLP初始化固定，不用测试分数追加调参。Logistic的C候选为0.1/1/10/100。样本不足的事件任务保留“不可识别”记录。

## 后续诊断与边界

- 表示有效秩、CKA、slot协方差、最终在线/target差异仅作诊断，不独立排名表示质量。
- TD/representation梯度用冻结权重和独立诊断批次计算，不执行optimizer.step。准确复用各历史目标，并另列统一正确折扣的敏感性结果。
- 行为分层按物理可行变道、路线意图、交互距离/车流等预定义条件；原critic Q-gap只解释为该critic自身偏好，不拿soft-Q减无熵回报做绝对校准。
- 动作分支优先采用从固定seed重置后重放完全相同动作前缀，必须核验分支前观测、回报、交通身份一致；不依赖未经验证的SUMO snapshot恢复。所有动作分支接同一最终full actor继续策略；不称最优Q。
- 最小动作分支预算：首12个诊断交通seed、MST行为轨迹；每条轨迹选第30决策以及其后首个观测距离≤10m且最近接近时间代理≤3s的状态（若存在且不重复）。保持车道的归一化速度−0.5/0/0.5，另加速度0下的物理可行左右变道，再加已观测的首动作作为重放校验；统一继续32决策或提前终止。分别学习无熵环境回报与未删失距离进展，不将两者加权拼成新奖励。该小样本分支只作为机制筛查，事件或动作回报差异不足时明确未判明。
- 若稀有事件或有限观测不足，明确未判明，并加入原始输入/物理状态诊断参照。历史整方法差异仍不能替代阶段3的 A/B/C 控制实验。
